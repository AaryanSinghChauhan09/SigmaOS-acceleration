# SigmaOS acceleration

This repository is currently a minimal `no_std` component identity scaffold. Its library exposes a `Component` named `SigmaOS-acceleration`.

The current source contains no multimedia, office, networking, SIMD, GPU, or other acceleration implementation. The package name alone does not indicate supported functionality.

## Build

```sh
cargo check --lib
```
